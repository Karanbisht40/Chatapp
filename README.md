🚀 LiveTalk

LiveTalk is a full-stack real-time chat and video communication platform built using the MERN stack. It supports friend requests, one-to-one and group messaging, video calling, and dynamic theme switching with a modern responsive UI.

🌐 Live Demo

🔗 https://chatapp-1-1dvq.onrender.com/

🛠 Tech Stack

Frontend: React.js, Tailwind CSS, DaisyUI, TanStack Query

Backend: Node.js, Express.js, MongoDB, JWT

Real-Time: GetStream Chat & Video APIs


✨ Features

🔐 Secure Authentication (JWT)

👥 Friend Request System (Send / Accept / Reject)

💬 One-to-One & Group Chat

⚡ Real-Time Messaging

✍ Typing Indicators & Read Receipts

📹 Video Calling

🎨 Multiple Theme Support

📱 Responsive Design
